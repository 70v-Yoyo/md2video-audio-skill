# Free Markdown Talking-Head Video Generation Skill (md2video-audio)

- Purpose: Automatically convert a local Markdown file into an MP4 video containing visuals and free voiceover.

## Execution Steps and Requirements

When this skill is triggered, strictly follow the steps below and execute them in the sandbox:

### 1. Environment Dependency Check and Installation

First, check whether the required dependencies are available. If any are missing, automatically install them:

```bash
pip install edge-tts moviepy markdown
npm install -g @marp-team/marp-cli
```

(Note: If the system reports that `ffmpeg` is missing, guide the user or automatically install it using `apt-get install -y ffmpeg`.)

### 2. Markdown File Preprocessing

- **Semantic Review + Content Optimization**: Check whether the file uses Markdown structural syntax to divide the content into logical sections and whether each section has an appropriate length. If not, perform **logical sectioning and formatting optimization**. Do not modify the original input MD file. Instead, save it as a new MD file named `new-original-prefix-timestamp`
  - Check and complete the document's heading hierarchy (ensure that `#` and `##` are used as natural visual scene transition points).
  - Standardize code block formatting and have AI automatically add natural transition or introductory narration above or around the code blocks.
- Split the MD file obtained in the previous step into a voiceover script and a presentation script. To ensure that the visuals and audio are perfectly synchronized without any offset, when writing these two Markdown files, the number of `---` separators on both sides **must remain exactly the same**, serving as the separator between each page.
  - Convert it into a logically natural voiceover script and save it as a new MD file named `speaking-original-prefix-timestamp`
  - Convert it into Marp format for generating PPT in subsequent scripts, and save it as a new MD file named `show-original-prefix-timestamp`
    1. Add several configuration lines to the very top of the Markdown file
    2. According to the semantic logic and Markdown paragraph structure, use `---` to separate each PPT page, as shown below

~~~markdown
---
marp: true
theme: gaia
_class: default
paginate: true
---
~~~

- Use these two saved **standardized intermediate filenames** as the parameters for subsequent script execution

### 3. Use the Python Script to Package Everything into a Video with One Command

- Use the two intermediate MD files generated above, namely the voiceover script and presentation script, as inputs, and execute the `ai-2md2marp2av.py` script in this skill directory with `python ai-2md2marp2av.py presentation.md voiceover.md`

  The script generates high-quality PPT images with Marp, then combines the images with the voice generated by Edge-TTS according to the corresponding page numbers.

### 4. Fallback Solution

- If the video cannot be generated successfully using the above steps, use the fallback solution: execute the `md2marp2av.py` script in this skill directory. If the video is still not generated correctly, execute the `md2video.py` script.
